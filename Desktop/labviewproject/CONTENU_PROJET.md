## 💻 ARDUINO/ (1 fichier)

### arduino_labview_communication.ino
**Taille :** 4.8 KB  
**Priorité :** ⭐⭐⭐ ESSENTIEL  
**Langage :** C/C++ (Arduino)

**Fonctionnalités :**
1. **Capteurs (3)**
   - LM35 (température) sur A0
   - Potentiomètre sur A1
   - Bouton poussoir sur D2

2. **Actionneurs (5)**
   - LED RGB (D9, D10, D11) - PWM
   - Servo moteur (D6)
   - Buzzer (D8)

3. **Communication série**
   - Baud Rate : 9600
   - Format : "T:25.5,P:512,B:0\n"
   - Fréquence : 100ms

4. **Commandes supportées**
   - LED:R,G,B - Contrôle RGB
   - SERVO:angle - Position servo
   - BUZZER:state - Buzzer ON/OFF
   - STATUS - Status complet

**Bibliothèques requises :**
- Servo.h (incluse)

**Structure du code :**
```cpp
// Définition des pins
// Variables globales
// setup()
// loop()
// readSensorsAndSend()
// receiveCommand()
// controlLED()
// controlServo()
// controlBuzzer()
// sendStatus()
```
